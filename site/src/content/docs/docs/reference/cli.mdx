This table is generated at build time from the help text in `src/cli.ts`, and a test checks that it lists exactly the commands the CLI accepts. Run `boardroom --help` (or `node dist/cli.js --help`) to see the same text.

Export and report commands use `--output <directory>` and create new files. Configuration and meeting commands persist records under `--data-dir`. Use `--json` where the help lists structured output. Exit codes are listed in [Exit codes](/docs/reference/exit-codes/).
