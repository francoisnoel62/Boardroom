These tables cover the recorded `decision` and shared `history` outputs, generated from the application's Zod schemas. Live inspection commands have distinct contracts documented in the [framing](https://github.com/francoisnoel62/Boardroom/blob/main/docs/framing-a-question.md), [analyses](https://github.com/francoisnoel62/Boardroom/blob/main/docs/independent-analyses.md), [revisions](https://github.com/francoisnoel62/Boardroom/blob/main/docs/sourced-revisions.md) and [decisions](https://github.com/francoisnoel62/Boardroom/blob/main/docs/live-decisions.md) guides.

<JsonOutput output="decision" />
